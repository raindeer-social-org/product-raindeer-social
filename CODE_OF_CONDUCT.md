# Code of Conduct

## Our Commitment

Raindeer Social is built by a small, high-trust team. We expect everyone who
contributes to this repository — employees, contractors, and any external
collaborators — to treat each other with respect and professionalism,
regardless of experience level, background, or role.

## Expected Behavior

- Communicate directly and respectfully, especially in code review, where
  tone doesn't always come across in text.
- Assume good intent. Critique the code, not the person.
- Be responsive to review feedback and open to being wrong.
- Keep discussion of technical decisions in the relevant issue or PR, not
  side channels, so context isn't lost.
- Respect that reviewers are gatekeeping quality, not blocking for its own
  sake — a requested change comes with a reason; ask if it isn't clear
  rather than assuming friction.
- Protect user, brand, and credential data at all times. Never commit
  secrets, API keys, OAuth tokens, or customer data to this repository.

## Unacceptable Behavior

- Harassment, discriminatory language, or personal attacks, in any project
  space (issues, PRs, commit messages, code comments).
- Dismissing or belittling another contributor's work or questions.
- Deliberately introducing insecure code, bypassing CI/review requirements,
  or force-pushing over shared branches without agreement.
- Sharing confidential brand, customer, or credential data outside
  authorized systems.

## Scope

This applies to all project spaces: GitHub issues, pull requests, code
review comments, commit messages, and any other official Raindeer Social
communication channel tied to this repository.

## Enforcement

Violations should be reported directly to the repository owners. Reports
will be handled promptly and confidentially. Consequences range from a
private warning to removal of repository access, depending on severity and
recurrence.
